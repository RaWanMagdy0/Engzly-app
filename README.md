# Engzly App

A home services mobile application that connects users with trusted service providers for a wide range of household needs.

⚠️ This project was built in collaboration with a Backend team.

## Demo
[Watch the App Demo](http://bit.ly/49CJ1xi)

## Features

- Authentication (Sign Up, Login, Forgot Password)
- Browse and book home services (Painting, Cleaning, House Shifting, and more)
- View offers and promotions
- Booking history
- User profile management
